# Typography

Read the project's saved identity. Map title, section heading, body, control labels and any numeric or editorial accents to explicit roles. For each role record family and approved fallback, size bounds, line height, measure and weight. Use the actual local font and verify it loads, or record the fallback in use.

Test the longest title, dense body copy, 200% zoom and narrow viewport with the actual implemented layout. Inspect wrapping and truncation on real content. Save role values in the project style contract and capture the broad and narrow layouts with font-load observations.
