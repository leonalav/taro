# Reference analysis

Record what the user wants to learn from each source. Give it a stable reference ID, keep its attached original or source URL, and record the frame, viewport or region for each observation.

Describe composition, type hierarchy, spacing, color, imagery and visible control states. Quote the source only as evidence. Report observed behavior with the action or timestamp that exposes it. Mark motion, data and offscreen behavior unknown from stills. Flag conflicts between references and any source-specific material that needs clearance.

Save the observations and uncertainties with the current design brief or project direction, using the reference IDs in follow-on decisions. Mark each recommended technique as a proposal until selected.
