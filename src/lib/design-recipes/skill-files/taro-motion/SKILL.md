# Motion choreography

Record each functional beat by stable layer or object ID and checkpoint name. Capture trigger, property, start and end states, units, duration or normalized scroll range, easing and expected final state. Name one controller for each property. Define equivalent touch and keyboard actions plus a still, immediate or otherwise reduced-motion experience.

Use Browser Review to execute the interaction sequence on the actual preview. Capture beginning, middle and end where progressive motion matters. Attach the viewport, motion preference and revision to each observation. Inspect the rendered behavior at rest and after visibility changes before making frame-time claims.
